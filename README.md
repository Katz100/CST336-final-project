# Countries
An Android app for getting details on selected countries

## Feature requirements
- Displays a list of over 200 countries that a user can pick from
- Displays details about a selected country from the REST Countries API
- Includes a page with details about me
- Includes naviagtion between the three screens.

## Additional features
- Includes a text field at the top of the country list page, allowing the user to filter countries based on a search term
- Includes unit tests for viewmodels

## Tech Used
- Kotlin
- Jetpack Compose
- Hilt for dependency injection
- Type-safe navigation for simple navigation between the three screens
- Retrofit for networking
- Follows Android's MVVM architecture
